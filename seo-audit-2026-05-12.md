# WhatIs.site — Comprehensive SEO Audit

**Date:** 2026-05-12
**Auditor:** Claude (multi-skill SEO audit, no Ahrefs/PSI access — see notes)
**Site:** https://whatis.site
**Corpus:** 1,615 articles · 1,690 sitemap URLs · 25 categories · Astro 5 / Vercel

---

## Executive Summary

The site is **well-architected at the template level** (excellent schema coverage, clean canonicals after the recent fix, fast static build, AI-crawler friendly) but is **bleeding visibility from three compounding problems** that no template fix can solve:

1. **A historical sitemap-vs-canonical slash mismatch killed indexation** — recent GSC audit (2026-05-09) shows **90.5% of 200 sampled URLs are "URL is unknown to Google."** The root cause was fixed in commit `6978b3c` but Google needs to recrawl, and trailing-slash duplicates are still served at 200 rather than 301-redirected.
2. **The internal link graph is one-way and orphaned at scale** — 388 articles (24%) have zero inbound links; only 9.58% of internal links are reciprocal. Hub pages absorb authority but don't redistribute it.
3. **Content is templated in ways AI/search detect** — 100% of hero alt text is the identical phrase `"Editorial photograph representing the concept of X"`; 73% of sitemap entries carry the same stale `lastmod=2025-07-15`; the byline is the same Organization on every YMYL article.

The three biggest wins, in priority order:
- **Force trailing-slash canonicalization at the Vercel edge** (1-line `vercel.json`).
- **Fix the 213 broken `relatedArticles` refs + backfill links to the 388 orphans.**
- **Rewrite the 1,615 hero alt-text strings to be unique and concrete.**

Banned-word humanization compliance is **99.81% clean** — only 3 articles carry all 15 violations. That part of the operation is working.

## Priority 1 — Indexation Crisis (Highest Impact)

### 1.1 Trailing-slash duplicates still serving 200

**Evidence:**
- `curl -I https://whatis.site/cybersecurity/` → `HTTP/1.1 200 OK` (not 301).
- `curl -I https://whatis.site/cybersecurity` → `HTTP/1.1 200 OK`.
- Both serve identical 54,220-byte HTML; canonical on both points to `https://whatis.site/cybersecurity` (no slash). ✓ Canonical is correct, but two URLs respond 200 with identical content.

**Impact:** High. Even with canonical tags, Google must crawl both, decide canonical, and consolidate signals — slow on a 1,690-URL site and the cause of the "URL is unknown to Google" cluster shown in `data/indexation-audit.json` (181/200 = 90.5%, with the inspected URLs carrying trailing slashes).

**Fix:** Add `vercel.json` with a permanent redirect rule. Static-output Astro can't intercept requests, so it must happen at the Vercel layer:

```json
{
  "trailingSlash": false,
  "redirects": [
    { "source": "/:path+/", "destination": "/:path+", "permanent": true }
  ]
}
```

After deploy, verify with `curl -I https://whatis.site/cybersecurity/` → expect `HTTP/1.1 308` (Vercel default) or `301`. Then resubmit the sitemap in GSC and request re-indexation of priority URLs.

**Priority:** 1 (blocks recovery of 90% of pages from index)

### 1.2 Sitemap `lastmod` is stale on 73% of articles

**Evidence:** `1,174 / 1,615` articles ship `lastmod=2025-07-15T00:00:00.000Z` despite being live. Only 438 carry the recent `2026-03-06` post-audit date. Real content edits aren't updating frontmatter `dateModified`, so the sitemap doesn't signal freshness.

**Impact:** Medium. Google deprioritizes recrawling URLs that look stale — which is exactly when you want them crawled (post-fix).

**Fix:** Either
- Bump `dateModified` on every article when fixing other issues (one batch update), then rebuild — `astro.config.mjs` already reads it correctly into the sitemap, OR
- Edit `data/edit-log.json` workflow to update `dateModified` on every edit.

**Priority:** 1 (do at the same time as 1.1 so resubmission carries fresh signals)

### 1.3 Homepage canonical vs sitemap slash mismatch

**Evidence:**
- Homepage canonical: `<link rel="canonical" href="https://whatis.site">` (no slash, no path)
- Sitemap entry for root: `<loc>https://whatis.site/</loc>` (trailing slash)

These point to the same resource but as different URL strings. The site-wide fix in `astro.config.mjs` line 33-38 strips trailing slashes for non-root entries but not the root.

**Fix:** In the sitemap serializer, also normalize the root: change `https://whatis.site/` → `https://whatis.site` to match the canonical. Or set the BaseLayout homepage canonical to `https://whatis.site/` to match the sitemap convention. Either way, both must agree.

**Priority:** 2

## Priority 2 — Internal Link Graph (Massive Latent Value)

Detailed report: `.audit-link-graph.json` + `scripts/audits/link-graph-audit.mjs`

### 2.1 388 orphan articles (24% of corpus)

**Evidence:** 388 articles have `incoming.length === 0` in `src/data/link-graph.json`. Sample: `barbecuing`, `basket-weaving`, `bookbinding`, `calisthenics`, `cocktail-making`, `coffee-roasting`, `comparative-mythology`, `cryptozoology`, `diy-electronics`, `doll-making`, `ancient-egyptian-history`, `australian-history`, `byzantine-history`, `choral-music`, `crab-fishing`.

**Impact:** These pages are reachable only via sitemap + category pagination. PageRank doesn't flow to them. Google's effective crawl depth is unbounded.

**Fix:**
- Run a script that, for each orphan, finds the 5 most semantically related published articles (by tag overlap and category) and inserts an internal link from those source articles' bodies.
- Aim for **minimum 5 inbound links per article** before re-running the audit.

**Priority:** 2

### 2.2 805 underlinked articles (50% < 3 inbound)

**Evidence:** Half the corpus has fewer than 3 inbound links. CLAUDE.md SEO rules state "5-10 internal links per article."

**Fix:** Same script as above, applied to all `incoming < 5` articles.

**Priority:** 2

### 2.3 Only 9.58% of internal links are reciprocal

**Evidence:** 1,830 of 19,104 directed edges have a reverse edge.

**Impact:** Topical clustering depends on bidirectional links. Hubs like `engineering` (355 incoming) and `management` (342 incoming) have only 33 and 27 outgoing — they sink authority without redistributing.

**Fix:** Process the top 20 hubs first. For each inbound link `A → hub`, programmatically add `hub → A` if it doesn't exist, in the hub's "Related Concepts" section.

**Priority:** 3

### 2.4 213 articles ship broken `relatedArticles` frontmatter

**Evidence:** Frontmatter slugs that don't have a corresponding `.md` file. Examples:
- `portrait-photography` references missing: `photography`, `lighting`, `art`, `fashion`, `film` (5/5 broken)
- `world-war-ii` references missing: `cold-war`, `fascism`, `democracy`, `nuclear-weapons`
- `manicuring` references missing: `cosmetology`, `beauty`, `self-care`, `fashion`

**Impact:** The RelatedArticles component appears to filter these out at render (no 404s on production), but the misleading data is committed to the corpus and the schema. If the renderer ever changes, you'd ship hundreds of 404s overnight.

**Fix:** Either (a) write the missing hub articles (`photography`, `cold-war`, `democracy` are obvious gaps), or (b) auto-prune broken refs from frontmatter via the bulk-internal-links script.

**Priority:** 2

## Priority 3 — On-Page Quality

### 3.1 100% identical hero alt text

**Evidence:** All 1,615 `heroAlt` values use the template `"Editorial photograph representing the concept of {topic}"`. Detailed in `.audit-images.json`.

**Impact:**
- Screen readers announce the same generic phrase 1,615 times — accessibility violation.
- Google Image Search gets no semantic content beyond the topic word.
- The phrase itself is a soft signal of AI-templated content.

**Fix:** A scripted rewrite that uses each article's title + a concrete entity from the first body paragraph. Example:
- Before: `"Editorial photograph representing the concept of abacus"`
- After: `"A wooden abacus with red and yellow beads arranged in counting positions"`

**Priority:** 2 (highest-leverage one-pass content fix on the site)

### 3.2 74 articles fail the GEO citation-worthiness rule

**Evidence:** First paragraph longer than 4 sentences. CLAUDE.md GEO rules: "First paragraph must be citation-worthy (clean definition, under 3 sentences)." Worst offenders include `quantum-mechanics`, `quantum-physics`, `quantitative-analysis`, `powerlifting`, `recycling`, `philosophy-of-music`.

**Impact:** AI Overviews, ChatGPT Search, and Perplexity preferentially cite concise self-contained definitions. A 6-sentence intro forces the model to summarize rather than quote — losing the citation.

**Fix:** Surgical edit on each — keep the definitional sentence, merge or move the next 2-3, push depth into the first H2.

**Priority:** 2

### 3.3 47 articles have zero contractions in body

**Evidence:** Banned-word audit (`.audit-content-quality.json`) flagged 47 articles with no contractions anywhere in the body. CLAUDE.md voice rules call for "smart friend explaining" prose.

**Impact:** Soft AI-content tell. Combined with the templated alt text, this stacks up to a perceived voice mismatch.

**Fix:** Pattern-replace `do not → don't`, `it is → it's`, `you are → you're`, `that is → that's` inside body prose (not headings, not schema fields, not external sources).

**Priority:** 3

### 3.4 Three articles carry 100% of banned-word debt

**Evidence:** Only `cybersecurity.md` (10 hits), `cryptocurrency.md` (3), `climate-change.md` (2) violate CLAUDE.md's banned-word list. `cybersecurity.md` alone: `landscape` ×5, `comprehensive` ×2, `navigate`, `at its core`, `serves as a`.

**Impact:** Low corpus-wide (99.81% clean), but the top-traffic Tier 1 articles are the violators. These are exactly the articles that need to read as human.

**Fix:** 15-30 minute hand-edit on three files.

**Priority:** 2 (cheap, high-prominence)

### 3.5 833 articles below tier word count (from existing `data/audit-report.json`)

**Evidence:** Per `data/audit-report.json` (run 2026-03-07): 833 articles fail the tier minimums. Tier 3 requires 1,200-2,000 words, many sit at 1,000-1,100. Tier 2 requires 2,000-3,000, many at 1,800-1,900.

**Impact:** Thin content hurts rankings against deeper competitors and reduces FAQ/section schema density.

**Fix:** Either downgrade tier (lower cost) or extend content (higher value). For underperformers, downgrade is fine; for keywords with search demand, extend.

**Priority:** 3

## Priority 4 — E-E-A-T

### 4.1 Single Organization author on YMYL topics

**Evidence:** Every article ships `author: "WhatIs Editorial"` as a `Schema.org/Organization`, not a named human. The `/about` page exists but doesn't list editorial bylines.

**Impact:** Google's December 2022 E-E-A-T update specifically prioritizes named expert authorship on YMYL queries — health, finance, legal, medical. Topics like `cybersecurity`, `accounting`, `nutrition`, `mental-health`, `contract-law` are all YMYL and currently lack an author entity.

**Fix:** Two paths:
- Lightweight: keep the Organization author but add an "About the editorial team" section to `/about` listing reviewers + credentials.
- Heavier: add an `authorBio` field to YMYL articles (or just Tier 1) with `Person` schema and a real name + credential.

**Priority:** 3

### 4.2 `foundingDate: "2026"` reads as new/inexperienced

**Evidence:** Homepage Organization schema literally declares `"foundingDate":"2026"` — true but signals to Google that this is a young site. Combined with no real reviews or media mentions, E-E-A-T trust signal is weak.

**Impact:** Low — but worth knowing. Google weighs site age + external citations.

**Fix:** No immediate fix beyond accruing backlinks and authentic mentions. Optionally remove `foundingDate` if the site originated earlier than the schema claims.

**Priority:** 4

## Priority 6 — GEO / AI Search

### 6.1 What's working

- `robots.txt` explicitly welcomes GPTBot, ClaudeBot, Googlebot, Bingbot.
- `llms.txt` (auto-generated via `scripts/generate-llms-txt.mjs`) is well-formed: title, > description, categories, top articles per category.
- `llms-full.txt` companion file exists with descriptions.
- FAQ schema is rich and quotable (avg 5 Q&A, each 80-150 words self-contained).
- `speakable` spec is included in Article schema — uncommon and useful for voice/Assistant queries.
- First paragraph definition pattern is consistent (when it's ≤3 sentences).
- 5+ external citations to .gov / .edu / OWASP / NIST per Tier 1 article.

### 6.2 What's gating citation rates

- **74 articles with bloated first paragraphs** (see 3.2) — the GEO ceiling.
- **No statistics in many shorter articles** — CLAUDE.md notes "Statistics improve AI citation by ~41%." Worth a sweep.
- **`llms-full.txt` lists every article** — that's a 1,600-line file. Some AI engines truncate. Consider keeping it but adding a `llms-priority.txt` with Tier 1 + 2 only.

**Priority:** 2 (paragraph trim) / 4 (priority file)
